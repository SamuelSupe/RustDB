RustDB - 查询本地磁盘和 S3/MinIO 上的 CSV、Parquet 与 Native 数据

使用方法：rustdb [选项] [命令]

配置验证：
  rustdb config validate [路径]        解析并验证版本化服务配置（默认 rustdb.toml）

不指定 -c 或 -f 时启动交互终端。SQL 语句必须以分号结束。

查询输入：
  -c, --command <SQL>                 执行 SQL 后退出
  -f, --file <路径>                   执行文件中的 SQL 后退出
      --format <table|csv|jsonl>      输出格式，默认 table
      --csv-null <文本>               CSV 输出中的 NULL 文本，默认空字段
      --metrics                       查询结束后输出执行指标

Native 数据库：
      --database <路径>               打开本地持久化 Native 数据库
      --native-engine-limit <大小>    完整 Native 数据库目录硬配额
      --native-default-table-limit <大小>
                                      单张 Native 表的默认硬配额
      --native-table-limit <表=大小>  单表硬配额，可重复；支持 schema.table
      --native-min-free-bytes <大小>  Native 文件系统至少保留空间，默认 1GiB
      --native-min-free-ratio <比例>  Native 文件系统至少保留比例，默认 0.10
  migrate <路径>                      验证数据库使用当前 Beta 格式；旧格式数据需重新导入
  native check <路径> [--json]        严格只读检查 marker、manifest 与全部数据文件
  native repair <路径> [--json]       只输出保守修复计划，不修改任何文件
  native repair <路径> --apply [--json]
                                      复核计划、备份元数据后执行安全修复
  import --database <路径> --table <名称> --location <URI>
         --format <csv|parquet> --import-id <ID>
         [--header <auto|present|absent>] [--delimiter <字符>]
         [--compression <auto|none|gzip|zstd>] [--json]
                                      幂等导入到新的 Native 表；同一请求重放不重复写入
  backup <数据库> <目标> [--state-root <路径>]
                                      备份 Native 与安全 HTTP 控制状态
  backup-check <备份> [--json]        校验本地目录或 s3:// 服务备份
  restore <备份> <新数据库> [--state-root <新路径>]
                                      恢复到全新数据库与服务状态目标
  diagnostics --database <路径> [--output <JSON>]
                                      生成脱敏、版本化的只读诊断报告

Beta 2 Native 数据库使用校验和 WAL 和快照隔离事务。SQL 支持 BEGIN、COMMIT、
ROLLBACK；提交前必须消费完或丢弃事务内的所有流式结果。

Beta 只读 HTTPS Shell：
  serve --database <路径>            前台启动单个 Native 数据库的 HTTPS 查询服务
        [--config <TOML>]             服务配置，当前目录有 rustdb.toml 时自动读取
        [--listen <IP:端口>]          默认 127.0.0.1:7400
        [--advertise-url <HTTPS URL>] 非回环监听时必填的客户端可访问地址
        [--state-root <路径>]          CA、服务证书、Token 和连接包的状态根目录
        [--result-directory <路径>]    后台查询结果的临时持久化目录
        [--result-ttl-secs <秒>]       已完成查询结果的保留时间，默认 3600
        [--result-global-limit <大小>] 全部已保留结果的总磁盘配额
        [--result-query-limit <大小>]  单个已保留结果的磁盘配额
        [--max-running <数量>]         最大同时执行查询数
        [--max-queued <数量>]          最大排队查询数
        [--max-query-time-secs <秒>] 服务端单查询时间上限
        [--query-memory-limit <大小>] 单 Query 内存 reservation 与硬上限
        [--query-spill-limit <大小>]  单 Query Spill reservation
        [--query-result-limit <大小>] 单 Query 结果 reservation
        [--principal-max-running <数量>] 单 principal 最大运行数
        [--principal-max-queued <数量>] 单 principal 最大排队数
        [--principal-memory-limit <大小>] 单 principal 内存 reservation
        [--principal-spill-limit <大小>] 单 principal Spill reservation
        [--principal-result-limit <大小>] 单 principal 结果 reservation
        [--principal-weight <1..1024>] 加权公平调度份额，Admin 无隐式优先级
        [--memory-limit <大小>]        服务查询内存上限
        [--threads <数量>]             计算工作线程数
        [--spill-engine-limit <大小>] 引擎 Spill 硬上限
        [--spill-query-limit <大小>]  单 Query Spill 硬上限
        [--s3-region <区域>]            服务端 AWS Region 覆盖
        [--s3-endpoint <URL>]           服务端 S3-compatible endpoint 覆盖
        [--s3-path-style]               服务端强制使用 S3 path-style 请求
        [--s3-allow-http]               服务端允许明文 S3 HTTP，仅限可信开发环境
        [--s3-anonymous]                服务端 S3 请求不签名，仅用于公开对象
        [--service-io-threads <数量>]  服务状态和结果 I/O 的固定线程数，默认 2
        [--admin-socket <路径>]        本机管理 socket；默认位于数据库服务状态目录
        [--tls-renew-interval-secs <秒>]
                                      检查并热加载临近过期 TLS 叶证书的周期
        [--no-auth]                     显式关闭认证，仅用于隔离开发环境

  service check --database <路径> [--state-root <路径>] [--result-directory <路径>]
                                      只读校验 principal、Query journal 与结果
  service repair --database <路径> [--state-root <路径>] [--result-directory <路径>]
        [--apply] [--json]
                                      仅修复可由 marker 证明归属的服务状态
  service status --database <路径> [--state-root <路径>] [--admin-socket <路径>]
                                      通过本机 socket 查看运行状态
  service reload-tokens --database <路径> [--state-root <路径>] [--admin-socket <路径>]
                                      原子重载持久化 principal/Token
  service rotate-token --database <路径> [--state-root <路径>] [--admin-socket <路径>]
        --principal <ID>
                                      在线添加重叠 Token 并立即重载
  service revoke-token --database <路径> [--state-root <路径>] [--admin-socket <路径>]
        --token-id <UUID>
                                      在线撤销 Token 并立即重载
  service shutdown --database <路径> [--state-root <路径>] [--admin-socket <路径>]
                                      请求有界优雅停服

  shell --profile <名称>               通过已导入 Profile 连接远程 HTTPS Shell
        [-c <SQL> | -f <文件>]         执行 SQL 文本或文件，两者都不指定时进入交互模式
        [--format <table|csv|jsonl>]   本地输出格式，默认 table
        [--csv-null <文本>]            CSV 输出中的 NULL 文本
        [--metrics]                   查询结束后输出服务端指标
        [--timeout-ms <毫秒>]          请求不超过服务端上限的较短超时

  profile import <连接包> --name <名称>
                                      通过可信离线渠道导入 CA、Token 和服务地址
  profile export --database <路径> --output <连接包>
        [--token-id <UUID>] [--server-url <HTTPS URL>]
                                      服务停止时导出指定 Token 的连接包
  principal list --database <路径>     服务停止时列出 principal
  principal create --database <路径> --id <ID> [--role <query|admin>]
                                      创建 principal 及首个本地 Profile Token
  principal set-enabled --database <路径> --id <ID> --state <enabled|disabled>
                                      启用或禁用 principal，保护最后一个 admin
  principal set-role --database <路径> --id <ID> --role <query|admin>
                                      修改角色，保护最后一个 admin
  token list --database <路径> [--principal <ID>]
                                      仅列出 Token UUID、归属、状态和有效期
  token rotate --database <路径> --principal <ID>
                                      新增可重叠轮换的 Token，不立即撤销旧 Token
  token revoke --database <路径> --token-id <UUID>
                                      撤销 Token 并删除本地明文 Profile Token 文件

持久外部数据源：
  datasource add-csv --database <路径> --name <名称> --location <URI> [--location <URI> ...]
        [--header <auto|present|absent>]
        [--compression <auto|none|gzip|zstd>] [--delimiter <字符>]
  datasource add-parquet --database <路径> --name <名称> --location <URI> [--location <URI> ...]
        [--schema-mode <strict|union|safe-widening>] [--hive-partitioning]
  datasource list --database <路径>
  datasource refresh --database <路径> --name <名称>
  datasource remove --database <路径> --name <名称>

HTTP Shell 安全边界：
  - 所有网络连接强制 TLS；非回环监听必须显式设置 --advertise-url。
  - 默认启用多 principal 认证；服务端 principals.json 只保存 SHA-256 digest，
    明文 Token 仅存在于权限 0600 的本地 Profile Token 文件。
  - query 角色只能访问自己创建的 Query；admin 可访问所有 Query；幂等键按 principal 隔离。
  - 客户端只通过命名 Profile 读取 CA 和 Bearer Token，不接受命令行明文 Token。
  - 远程 SQL 仅允许 SELECT/WITH/VALUES/SHOW/DESCRIBE/EXPLAIN/EXPLAIN ANALYZE；拒绝
    DDL、DML、事务、维护和数据源管理。
  - 远程 SQL 拒绝 read_csv/read_parquet 直接路径，只能读取 Native 表、
    系统表和服务端本地预先持久注册的 CSV/Parquet 数据源。
  - 请先停止 serve 再执行 profile 修改或 datasource 管理。

执行资源：
      --memory-limit <大小>           查询内存上限，例如 512MiB、2GiB
      --threads <数量>                计算工作线程数
      --batch-size <行数>             Arrow 执行批次的目标行数
      --io-concurrency <数量>         Scan 的最大文件/对象并发数
      --metadata-cache <大小>         Parquet 元数据缓存上限，0 表示禁用
      --max-concurrent-queries <数量> 最大并发查询数

CSV：
      --csv-target-morsel-bytes <大小>       每个解析 morsel 的目标解压字节数
      --no-csv-parallel-single-file          禁用单个 CSV 文件的并行解析

Parquet：
      --parquet-page-index <auto|disabled>   Page Index 裁剪策略
      --parquet-bloom-filter <auto|disabled> Bloom Filter 裁剪策略
      --parquet-pruning-metadata <大小>       单查询裁剪元数据上限

Spill：
      --spill-directory <路径>               Spill 文件目录
      --spill-engine-limit <大小>             全引擎 Spill 字节上限
      --spill-query-limit <大小>              单查询 Spill 字节上限
      --spill-min-free-bytes <大小>           Spill 文件系统必须保留的空间
      --spill-io-threads <数量>               专用 Spill I/O 线程数
      --spill-partition-target-bytes <大小>   自适应 Hash 分区目标大小
      --max-repartition-depth <深度>          最大递归重分区深度
      --max-spill-write-amplification <倍数>  最大累计 Spill 写放大
      --runtime-filter-bytes <大小>           Join Runtime Filter 内存预算

S3/MinIO：
      --s3-region <区域>               AWS Region
      --s3-endpoint <URL>              S3-compatible endpoint
      --s3-path-style                  强制使用 path-style 请求
      --s3-allow-http                  允许明文 HTTP，仅用于可信开发环境
      --s3-anonymous                   匿名访问，不签名请求

通用：
      --help-zh                        显示本帮助
  -h, --help                           显示英文帮助
  -V, --version                        显示版本

大小单位支持 B、KB、MB、GB、KiB、MiB、GiB。
凭证通过 AWS 默认凭证链提供；命令行不接受明文 Access Key 或 Secret Key。

示例：
  rustdb -c "SELECT count(*) FROM read_parquet('/data/*.parquet')"
  rustdb -f query.sql --format csv --memory-limit 2GiB --threads 4
  rustdb --database ./warehouse -c "BEGIN READ ONLY; SELECT count(*) FROM events; COMMIT"
  rustdb --database ./warehouse --native-engine-limit 20GiB \
    --native-default-table-limit 5GiB --native-table-limit events=10GiB \
    -c "SELECT count(*) FROM events"
  rustdb migrate ./warehouse
  rustdb native check ./warehouse
  rustdb native check ./warehouse --json
  rustdb native repair ./warehouse
  rustdb native repair ./warehouse --apply --json
  rustdb import --database ./warehouse --table events --location ./events.csv \
    --format csv --import-id events-2026-07-19 --header present
  rustdb backup ./warehouse ./warehouse-backup --state-root ./service-state
  rustdb backup-check ./warehouse-backup
  rustdb restore ./warehouse-backup ./warehouse-restored --state-root ./restored-state
  rustdb diagnostics --database ./warehouse --output diagnostics.json
  rustdb --s3-region us-east-1 -c \
    "SELECT * FROM read_parquet('s3://bucket/events/*.parquet') LIMIT 10"
  rustdb datasource add-parquet --database ./warehouse --name events \
    --location 's3://bucket/events/*.parquet' --schema-mode safe-widening
  rustdb serve --database ./warehouse
  rustdb principal create --database ./warehouse --id analyst --role query
  rustdb token rotate --database ./warehouse --principal analyst
  rustdb token list --database ./warehouse --principal analyst
  rustdb profile export --database ./warehouse --token-id <UUID> \
    --output analyst.rustdb-profile
  rustdb profile import warehouse.rustdb-profile --name warehouse
  rustdb shell --profile warehouse -c "SELECT count(*) FROM events" --format table
  rustdb shell --profile warehouse -f report.sql --format csv --metrics

交互终端命令：
  .tables    列出已注册的外部表
  .help      显示英文帮助
  .help zh   显示中文帮助
  .quit      退出
